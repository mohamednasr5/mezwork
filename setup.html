خطأ 401 - غير مصرح به

Firebase يرفض الاتصال. الحل أدناه 👇

📋 الخطوة 1: افتح Firebase Console

اذهب إلى Firebase Console

🗄️ الخطوة 2: اختر Realtime Database

من القائمة الجانبية، اختر "Realtime Database"

📝 الخطوة 3: غيّر قواعد الأمان (Rules)

استبدل القواعد الحالية بهذه:

{ "rules": { ".read": true, ".write": true } }

✅ الخطوة 4: انشر القواعد

اضغط على زر "Publish" لحفظ التغييرات

✅ تم الاتصال بنجاح!
